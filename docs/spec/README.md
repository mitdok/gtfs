# GTFS公開データ生成WEBサービス 仕様書(通称「西沢ツール」WEB版)

本ディレクトリは、表形式のダイヤ入力からGTFS（GTFS-JP / GTFS-RT）形式の公開用オープンデータを生成・配信するWEBサービスの仕様書一式です。

> **プロジェクト仮称: `gtfs-studio`（以下「本サービス」）**
> 既存の「西沢ツール」（Excel/スプレッドシートマクロによるGTFS-JP生成ツール）の思想をWebアプリケーションとして再構築し、取込（インポート）とWeb UI編集の両方を備えることを目的とします。

## プロジェクトの立ち位置

無償公開された「西沢ツール」（西沢明氏）が日本のGTFS-JP普及に果たした功績を出発点とし、その志を継承する。近年は商用SaaSも登場しているが、本サービスは**ソースコードをOSSとして公開**し、SaaS提供と自治体オンプレ運用の双方を可能にする。継続的改善は**コミュニティサポート**を中核に据え、ベンダロックインのないオープンな共通基盤を社会に残すことを目的とする。詳細は [01-overview](./01-overview.md) 1.4 を参照。

## 設計の基本方針（サマリ）

1. **パターン中心モデル**: 「系統パターン（停留所の並び）」を一次データとし、便（trip）は基準時刻＋停留所オフセットで展開する。西沢ツールのダイヤ入力に対応する。
2. **取込と編集の両立**: 既存の西沢ツール様式 / CSV / GTFS-JP zip をインポートし、Web UIで追補・修正できる。
3. **常時バリデーション**: 編集中・出力前にGTFS-JP仕様準拠チェックを行い、致命的エラーがある場合は公開をブロックする。
4. **公開URLの安定配信**: 生成した `gtfs.zip` を版管理し、安定したフィードURL（最新版エイリアス）で常時配信する。
5. **静的と動的の分離**: GTFS-JP（静的）とGTFS-RT（動的）はデータソース・配信経路を分離し、GTFS-RTは後続フェーズで段階導入する。
6. **地図は自前MapLibre地図基盤を疎結合利用**: 停留所・shape編集は自前のMapLibre地図基盤を「地図アダプタ」越しに使う。地図仕様が未確定でも編集機能を先行実装でき、地図が無い環境でも数値編集で成立する（[02](./02-requirements.md) F-10 / [04](./04-screens.md) 4.4）。
